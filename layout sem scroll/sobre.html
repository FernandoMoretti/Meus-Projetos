Nossa História

O Café da Silva nasceu em Campo Grande, Mato Grosso do Sul, a partir de um sonho: criar uma cafeteria com foco principal no café.

Nossa proposta é simples: oferecer cafés de qualidade, valorizando cada preparo e cada sabor.
Por isso, nosso cardápio é voltado especialmente para cafés quentes e gelados, com opções para diferentes momentos e preferências.

Mais do que servir uma bebida, queremos criar um espaço para quem realmente aprecia café. Seja para começar o dia, fazer uma pausa ou experimentar novos sabores, o Café da Silva foi pensado para tornar cada xícara uma experiência especial.
